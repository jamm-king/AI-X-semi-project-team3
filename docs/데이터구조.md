## 회귀 모델 테스트
| 테스트 | 기준일까지의 기록으로 만드는 입력 |
|---|---|
| **① 직전 4주 기준 예측** | 제품별 직전 28일 판매수량 합계. 이 값을 그대로 다음 28일의 예측값으로 사용합니다. 별도 학습이 필요 없습니다. |
| **② 판매·거래처 모델** | ①의 수량에 최근 4·12주 판매량, 판매 발생 주 수, 마지막 판매 후 경과일, 구매 거래처 수, 반복 구매 거래처 수 등을 추가합니다. 전표 식별자가 없다면 같은 거래처의 여러 행을 그대로 주문 횟수로 세지 않고, **서로 다른 구매일 수**를 사용할 수 있습니다. |
| **③ 매입 정보 추가 모델** | ②의 입력을 그대로 두고 최근 4·12주 매입량, 매입 발생일 수, 마지막 매입 후 경과일을 추가합니다. ②와 같은 모델·평가 기간을 사용하면 매입 이력의 추가 효과를 확인할 수 있습니다. |

## 회귀 모델 학습 데이터 구조
| 컬럼명 | 자료형 | 정확한 정의 | 사용처 |
|---|---|---|---|
| `as_of_date` | 날짜 | 예측 기준일 `D` | 행 식별·시간순 분할 |
| `product_id` | 문자열 | 제품명과 포장 단위를 정리해 부여한 제품 ID | 행 식별·②③ 범주형 입력 |
| `brand` | 문자열 | 표준화한 브랜드명 | ②③ 입력 |
| `sales_qty_28d` | 정수 | 최근 28일의 양수 수량 합계 | ① 예측값·②③ 입력 |
| `sales_qty_84d` | 정수 | 최근 84일의 양수 수량 합계 | ②③ 입력 |
| `sales_days_84d` | 정수 | 최근 84일 중 해당 제품이 한 번 이상 팔린 날짜 수 | ②③ 입력 |
| `days_since_last_sale` | 정수 또는 결측 | `D − 마지막 판매일`. 기준일에 팔렸으면 0 | ②③ 입력 |
| `buyer_count_84d` | 정수 | 최근 84일간 해당 제품을 구매한 고유 거래처 수 | ②③ 입력 |
| `repeat_buyer_count_84d` | 정수 | 최근 84일간 해당 제품을 **서로 다른 날짜에 2회 이상** 구매한 고유 거래처 수 | ②③ 입력 |
| `purchase_qty_28d` | 정수 | 최근 28일간 해당 제품의 매입 수량 합계. 음수 수량의 절댓값을 합산 | ③ 입력 |
| `purchase_qty_84d` | 정수 | 최근 84일간 해당 제품의 매입 수량 합계. 동일한 방식으로 계산 | ③ 입력 |
| `days_since_last_purchase` | 정수 또는 결측 | `D − 마지막 매입일`. 기준일에 매입했으면 0 | ③ 입력 |
| **`target_sales_qty_next_28d`** | **정수** | **기준일 다음 날부터 28일간 해당 제품의 양수 판매 수량 합계** | **공통 정답 `y`** |

## 시계열 모델(딥러닝) 학습 데이터 구조
| 컬럼명 | 자료형 | 한 행에 기록할 값 |
|---|---|---|
| `product_id` | 문자열 | 포장 단위까지 구분한 표준 제품 ID |
| `week_end_date` | 날짜 | 해당 주의 일요일 날짜. `product_id`와 합쳐 행을 고유하게 식별 |
| `brand` | 문자열 | 해당 제품의 표준 브랜드명 |
| `sales_qty` | 정수 | 해당 주 양수 판매수량 합계. **과거 주에서는 입력, 미래 주에서는 정답** |
| `sales_days` | 정수 | 해당 주에 제품이 한 번 이상 팔린 날짜 수. 범위는 0~7 |
| `buyer_count` | 정수 | 해당 주에 제품을 산 고유 거래처 수 |
| `repeat_buyer_count_84d` | 정수 | 해당 일요일까지 최근 84일간, 이 제품을 서로 다른 날짜에 2회 이상 산 고유 거래처 수 |
| `purchase_qty` | 정수 | 해당 주 음수 매입수량의 절댓값 합계 |
| `purchase_days` | 정수 | 해당 주에 제품을 한 번 이상 매입한 날짜 수. 범위는 0~7 |
